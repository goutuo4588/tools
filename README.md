## 收录的软件

下面这些是我用着顺手、顺手收录分流的第三方软件。需要最新版或想支持作者，请走各自的官网 / 项目主页。

### 1. OpenSpeedy（游戏变速 · 绿色版）
开源免费的游戏变速工具，通过 Hook Windows 时间函数实现加速 / 减速，无需管理员权限。
- 项目主页：https://github.com/game1024/OpenSpeedy（许可证 GPL-3.0）
- 下载 `OpenSpeedy-3.3.8-portable-signed.zip`，解压后运行 `openspeedy.exe`
- 下载见 Release：[openspeedy-v3.3.8](https://github.com/goutuo4588/tools/releases/tag/openspeedy-v3.3.8)

### 2. Watt Toolkit（Steam++ · 绿色版）
开源的 Steam 多功能工具箱：游戏加速、库存管理、成就统计等。
- 项目主页：https://github.com/BeyondDimension/SteamTools（许可证 MIT）
- 下载 `Steam++_v3.1.0_win_x64.7z`，**需 7-Zip / Bandizip / WinRAR 解压**，解压后运行 `Steam++.exe`
- 下载见 Release：[watt-toolkit-v3.1.0](https://github.com/goutuo4588/tools/releases/tag/watt-toolkit-v3.1.0)

### 3. Wireshark（Windows x64 安装包）
网络协议分析器行业标准，抓包、排查网络故障、分析协议通信。
- 官方网站：https://www.wireshark.org/（许可证 GPL-2.0）
- 下载 `Wireshark-4.6.8-x64.exe` 双击安装，**安装时务必勾选 Npcap**，否则抓不到包
- 下载见 Release：[wireshark-v4.6.8](https://github.com/goutuo4588/tools/releases/tag/wireshark-v4.6.8)

### 4. Geek Uninstaller（便携版）
单文件卸载工具，卸载后自动扫描残留文件与注册表，比系统自带卸载干净。
- 官方网站：https://geekuninstaller.com/（免费软件，非开源）
- 下载 `geek.exe` 双击即运行，无需安装
- 下载见 Release：[geek-uninstaller-portable](https://github.com/goutuo4588/tools/releases/tag/geek-uninstaller-portable)

## 使用方法
1. 到上方对应 Release 下载工具。
2. 绿色版解压后直接运行 exe 即可；Wireshark 是安装包，双击按提示安装（记得勾选 Npcap）。
3. 若被系统 / 杀软拦截，请信任后运行——自包含程序常被误报，属正常现象。
