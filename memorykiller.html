核心功能

三管齐下，释放系统余量

针对内存、CPU 与 GPU 共享内存的占用瓶颈，提供可验证、可审计的优化手段。

内存释放

清理待机列表与已修改页，回收进程工作集，立即腾出可用内存，缓解卡顿与无响应。

CPU 降温

降低后台进程的 CPU 占用峰值，缓解高负载下的温度积聚与界面卡顿，运行更安静稳定。

GPU 共享内存缓解

释放被显存共享占用的系统内存，提升图形与游戏场景下的稳定性，避免因共享内存耗尽导致的崩溃。

工作原理

基于系统接口的安全释放

所有操作均调用 Windows 公开内存管理接口，仅整理与回收，不破坏任何进程状态。

1

清理待机列表

释放被标记为待机（standby）的冗余内存页，将空间归还可用池。

2

回写已修改页

将已修改（modified）页刷回磁盘并回收，进一步释放物理内存。

3

回收工作集

按需修剪进程工作集上限，压低常驻内存占用，保留可运行的最小集合。

4

结果可验证

释放前后可用内存、CPU 与共享内存占用均可在系统监控中对照核验。

安全机制

稳健设计，默认拒绝风险

安全性是工具的前提。内存杀手以多重护栏确保操作不伤害系统与数据。

No Kill

绝不终止进程

仅清理与回收内存，绝不杀死任何用户或系统进程，数据与会话状态不受影响。

Blacklist

系统进程黑名单

内置受保护进程清单，核心系统组件与关键服务一律豁免，避免误伤。

UAC

管理员权限隔离

通过 UAC 提权运行，操作受控、可审计；无提权则不执行任何释放动作。
