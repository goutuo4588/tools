# 具坊 · 一键密码重置网站

客户在网页申请找回密码 → 管理员后台一键把该客户密码重置为 12 位随机密码（大小写字母 + 数字）→ 通过你的 163 邮箱把新密码发给客户。

## 功能
- 客户自助注册（用户名 + 邮箱 + 密码）
- 公开申请找回页（图形验证码 + 限频防刷）
- 管理员登录后台（强密码 + 会话鉴权）
- 一键重置：生成随机密码 → 更新客户 → 163 邮件发送 → 标记完成
- 密码仅经邮件送达，不在页面显示、不以明文存储（scrypt 哈希）

## 技术
纯 Node.js 原生实现，**零依赖、无需 npm install**，一个 `node server.js` 就能跑。

## 本地运行
1. 需要 Node.js 18+（本机已自带，不用安装任何包）
2. 复制配置：`cp .env.example .env`，编辑填入：
   - `ADMIN_PASS`：管理员后台密码（**务必改成强密码**）
   - `MAIL_USER` / `MAIL_PASS` / `MAIL_FROM`：163 邮箱及 SMTP 授权码
3. 启动：`node server.js`（默认端口 3000）
4. 浏览器打开：
   - 客户申请：http://localhost:3000/
   - 客户注册：http://localhost:3000/register
   - 管理员后台：http://localhost:3000/admin

> 未配置 163 邮箱时，发信为「模拟模式」——只在服务端控制台打印邮件内容，方便本地调试，不会真发。

## 163 邮箱授权码获取
1. 登录 163 邮箱网页版 → **设置 → POP3/SMTP/IMAP**
2. 开启「IMAP/SMTP 服务」或「POP3/SMTP 服务」
3. 按提示短信验证，获取 **授权码**（注意：是授权码，不是邮箱登录密码）
4. 把授权码填进 `.env` 的 `MAIL_PASS`

## 部署到公网（让别人能访问申请页）
推荐 **Render** 或 **Railway**（免费层即可）：
1. 把本目录推到你的 GitHub 仓库
2. 在 Render / Railway 新建 Web Service，关联该仓库
3. 启动命令：`node server.js`；在平台的环境变量里填 `ADMIN_PASS`、`MAIL_USER`、`MAIL_PASS`、`MAIL_FROM`（`PORT` 平台会自动注入）
4. 部署完成后得到一个公网网址（如 `xxx.onrender.com`），客户即可访问并申请

> 想绑定自己的域名（如 `jvfang.com`）：在平台后台设置自定义域名即可。
> **切勿把 `.env` 提交进仓库**——敏感信息一律填在平台的环境变量里（`.gitignore` 已忽略 `.env` 和 `data/`）。

## 安全说明
- 管理员后台务必设置**强** `ADMIN_PASS`
- 客户密码以 scrypt 哈希存储；重置后的新密码只通过邮件发送，服务器不留存明文
- 公开申请页带图形验证码 + 限频，防机器人刷
- 申请找回不返回「账号是否存在」，避免被人枚举账号
