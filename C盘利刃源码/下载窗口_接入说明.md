## 二、调用时机：三个方案怎么选

| 方案 | 做法 | 评价 |
|---|---|---|
| A. 主窗口出现**之前**弹 | 免责协议 → **下载窗口** → 主窗口 | ✅ **已采用**。用户第一眼就看到，就是安装器那种「先选位置」的体感，符合你说的"第一时间弹出来" |
| B. 主窗口出现**之后**弹 | 主窗口 → 下载窗口 | ✗ 用户已经看到主界面了再被拦一道，顺序别扭，还容易和后台的快捷方式线程抢焦点 |
| C. 挂按钮手动触发 | 需要时点按钮 | ✗ 你明确要求"不新增独立触发方式"，且用户不知道有这功能，等于没有 |

最终规则（写在 `run_download_window_if_needed` 里）：

- 清单**非空**（真有东西要下）→ **每次启动都弹**，用户要有机会确认/改位置
- 清单**为空**（现在的状态）→ **只在还没记住保存目录时弹一次**，当首次引导，之后不再拦
- `download_popup_on_start = False` → 彻底不弹

理由：每次都弹一个没有内容的窗口会烦人；但真有下载内容时不弹就等于没入口。

## 四、生命周期与卡顿（第 3 条要求）

- **不卡主线程**：下载跑在 `DownloadWorker(QThread)` 里，进度通过信号回传，主线程只负责刷进度条
- **不会重复弹**：`run_download_window_if_needed` 每次只 new 一个实例，`exec()` 模态显示，函数返回后 `deleteLater()`
- **关闭即释放**：`finally` 里 quit + wait(3000) 收线程，`closeEvent` 还有一层兜底，避免线程回调打到已销毁的控件上
- **取消不留垃圾**：未开始点取消 → 零写入；下载中点取消 → 停线程 + 删 `.part` + 删本次已落盘文件，完全回滚
- **取消不影响启动**：返回 `("", [])`，后面照常进主窗口

## 五、打包

`download_dialog.py` 是纯 .py，PyInstaller 靠 `import` 自动收集，`C盘利刃.spec` **不用改**，也不用加 datas。

完整出包链路（脚本都在工作目录，中文文件名交给 Python 处理，别用 Git Bash 手敲）：

1. `build.py` —— 复制源码到 `pack/`，spec 转 ASCII 名后调 PyInstaller → `pack\dist\C盘利刃.exe`（36.6 MB）
2. `compile_iss.py` —— 复制 iss 转 ASCII 名后调 ISCC → `pack\setup_output\C盘利刃_安装器_V2.2.exe`（38.3 MB）
3. `test_install.py` —— 静默装一次再卸载，冒烟验证

> 坑：Git Bash 传参会吞掉文件名开头的 `C`（当盘符解析），`C盘利刃.spec` 会变成 `盘利刃.spec`。所以 spec/iss 都先复制成 ASCII 名再交给工具。
